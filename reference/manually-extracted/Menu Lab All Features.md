## Catalog Page

Each Catalog Page follows the same pattern which include:

1. An animated logo that shows up on the page with an effect, then some short message under it, then the button, which has it’s own animation, the background is usually also animated in some form. The button says “Show Menu” and somewhere on that main page is a language selector  
     
2. After clicking show menu, you’re directed to the Categories page, same restaurant logo and language selector remain near the header, then a grid of cards that show each category (Drinks, Salad, Dessert, etc) along with a picture.  
     
     
3. Additionally, each catalog page has transition animations for when you move between pages.  
4. After clicking on a category, you get the list of items, which includes a name and price  
   ( there’s name, price, Turkish name, weight, and emojis that signify the type of food)  
   Turkish name only shows up when the language is not Turkish, whether it’s the main or sub title of the card depends on the specific restaurant.  
5.   
6. Product Page,  A popup page (modal dialog), with the same info but additionally, nutritional details, and a brief explanation of the product   
7. The menus only serve to present the available options, there’s no ordering or cart functionality.  
8. The Footer of the 2nd main page (the one with category cards), has social media buttons (call us, instagram, tiktok, google maps location button) and then a rate us button (modal of internal rating system), then a button that re-directs to google reviews
